# BanfieldBio-Compliance — search engine policy
#
# Everything published here is material explicitly classified `public` in
# the BanfieldBio inventory, and is meant to be found: a receiving lab or a
# responder should be able to search for an SDS and land on it.
#
# There is no /shipment/ surface. Per-shipment documents carry ship dates,
# quantities, lot numbers and CAS, and are served from the gated endpoint,
# not from this site. The Disallow below is a tombstone for URLs that used
# to exist, not protection for anything currently here — this repo is
# public, so its file tree is browsable regardless of what robots.txt says.
# Nothing is kept out of a crawler's reach by this file; things are kept
# out by not being committed.

User-agent: *
Disallow: /shipment/
Allow: /item/
Allow: /sds/
Allow: /
